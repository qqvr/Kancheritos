# 🛒 Kancheritos

**Kancheritos** es una aplicación web **hecha exclusivamente para mi mamá**, pensada para la **gestión simple de productos por código** en su tienda.

No es una aplicación pública:  
👉 **solo ella puede acceder**, usando **su Gmail y una contraseña personalizada**.

🔗 **Acceso a la página:**  
https://qqvr.github.io/Kancheritos/

---

## 👩‍👧 ¿Para quién es esta página?

Esta página fue creada **únicamente para mi mamá**, a pedido de ella, para ayudarla a:

- Ordenar sus productos
- Buscar rápido por código
- No mostrar stock innecesario
- Usar una herramienta simple y directa

El acceso está protegido con **Firebase Authentication**, por lo que **nadie más puede ingresar** sin el mail y contraseña correctos.

---

## 🚀 ¿Qué hace la página?

Funciona como un **catálogo privado de productos**, conectado a Firebase.

### ✅ Funciones principales

- 🔐 **Inicio de sesión privado**
  - Acceso solo con **el Gmail autorizado**
  - Contraseña personalizada

- ➕ **Agregar productos**
  - Cada producto incluye:
    - Código numérico
    - Nombre
    - Precio
    - Proveedor

- 🔍 **Buscar productos (SOLO por código)**
  - Se ingresa **únicamente el código numérico**
  - Si el código existe:
    - Se muestran todos los datos del producto
  - ❌ No se busca por nombre
  - ❌ No se muestran productos si no se ingresa un código

- 🗑 **Eliminar productos**
  - Eliminación directa desde la base de datos

---

## ❌ Qué NO hace (a propósito)

- No muestra todo el stock
- No permite buscar por nombre
- No muestra productos automáticamente
- No es una app pública

Todo funciona **solo bajo demanda por código**, de forma privada.

---

## 🧠 ¿Cómo usarla?

1. Iniciar sesión con el Gmail autorizado
2. Agregar un producto con su código
3. Ir a la sección de búsqueda
4. Escribir el código
5. Ver los datos del producto
6. (Opcional) eliminar el producto
